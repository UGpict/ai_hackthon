# 評価セットに対してツールが出すべきこと

`demo-analysis-lab.json` を流したとき、人間がこれを満たせば合格。モデルの文言一致は不要。

## 上位に来るべき

### 1. 食品包装フィルム × 重金属 × EU向け成績書

- 実問: あり（原文を残す）
- 根拠: 含有重金属・ICP-MS・成績書は可。**溶出試験は cannot にあるので「溶出なら不可/外注」と書く。含有と溶出を混ぜない。**
- 空白: サイトは「ICP-MSを行っています」だけで、包装・EU・溶出/含有の切り分けが無い
- 商談近さ: 可否と成績書
- 行動: 新規（または事業紹介への追記だが、条件が長いので新規Q&Aがよい）
- 禁止: EUの特定書式を「出せる」と発明しない。cannot の通り未対応のことがある

### 2. 試料10g・前処理から

- 根拠: 十グラム前後の相談事例、標準は20g
- 空白: 必要試料量がサイトに無い
- 記事の核: 必要量の目安と、足りないときの判断（相談 / お断り）

### 3. RoHS追加物質 × 樹脂ペレット × 検出下限

- 根拠: RoHSスクリーニング実績、ICP-MS
- 空白: 検出下限も対象マトリクスも書いていない
- `[要確認]`: 具体的な検出下限数値は入力に無いので発明しない。聞く項目として出す

## 出してはいけない

- 「ICP-MSとは」系。サイトの装置名紹介の焼き直し
- 「ISO 17025を取得しています」単独。サイトの認定ページで既に答えている
- 微生物・食品栄養。cannot
- 入力に無い ppm 値、認定範囲の詳細、EU公式書式名

## 止まってほしい入力変異

- `realQuestions` を2件に削る → `blocked.too_few_questions` と聞き方リスト
- `capabilities.evidence` と `can` を空 → 根拠なしで推薦しない
