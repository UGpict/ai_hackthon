# きずあと (Kizuato)

**痛い検索語の SERP だけをハックする。** 業務改善でも、万能コンテンツAIでもない。

Google の “痛い瞬間検索” 枠を、固定型ページ × キャラ付きエージェント量産で奪う。

## ハック対象 / 捨てるもの

- OWN: 痛い瞬間クエリ、固定ページ型、FAQ・内部リンク縫合
- REFUSE: 人生相談全般、マーケ万能ツール、業務改善ダッシュボード、なんでもブログ工場

## ルート

- `/` — ハック宣言 + SERP wedge + 三人
- `/ops` — SEOハック室（クエリ投入 → 下書き）
- `/kizu` — 奪いにいってるクエリ索引
- `/kizu/[slug]` — プログラム的 SEO ページ

## 開発

```bash
npm install
npm run dev
```
