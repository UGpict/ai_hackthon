# きずあと (Kizuato)

仕事ログに出る顧客の痛み言葉だけを、Pain SERP へ刺す。

ミツバチ（ミツ / ハニ / コム）は進捗の顔。本体は **抽出規則 + 人の採用ゲート + 出典付き下書き**。

## 50代プログラマ向けの正直な話

- 抽出は LLM ではない（`src/lib/pain-extract.ts` のローカル規則）
- ミツバチのアニメはネットワーク呼び出しではない
- 拒否ルールはスライドではなくコードとテストで強制
- 下書きは人が採用した候補からだけ作る

## ルート

- `/` — ハック宣言 + ハニカム
- `/ops` — 仕事ログ → 抽出 → 採用 → 光るセル → 下書き
- `/kizu` — クエリ索引

## 開発

```bash
npm install
npm test
npm run dev
```
