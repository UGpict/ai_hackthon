# きずあと (Kizuato)

**痛い検索の1位を、ミツバチで占領する。**

業務改善でも、コンテンツ工場でもない。人が弱い瞬間に打つ検索語（Pain SERP）だけを狙い、ハニカムの光ったセル＝占領したGoogle枠として可視化する。

## 新規性
SEO全般ではない。「痛い瞬間の検索」だけを領地化し、占領状況をハニカムで見せる。

## ワクワク
競合のまとめ記事の上に自分の枠が刺さり、セルが光るたびに「取った」が見える。

## ルート
- `/` — 占領宣言 + 新規性
- `/ops` — SERP占領室（クエリ → レイド → 光るハニカム → 占領ページ）
- `/kizu` — 占領一覧

```bash
npm install
npm run dev
```
