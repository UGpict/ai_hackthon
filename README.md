# きずあと (Kizuato)

痛い検索語の SEO だけに特化したハック。原体験の塊みたいな辛さを、検索結果の一点突破で薄める。

サグリ（掘る）・ケズリ（削る）・トジ（閉じる）が、キャラとして「自分たちのために働いてる感」を可視化しながらページを回し続ける。

## ルート

- `/` — ブランド + 三人 + ライブ稼働ログ
- `/kizu` — 痛い検索語の索引
- `/kizu/[slug]` — プログラム的 SEO ページ（JSON-LD）
- `/ops` — エージェント稼働室（クエリを投げて三人を動かす）

## 開発

```bash
npm install
npm run dev
```

コンテンツ追加は `src/lib/pains.ts`。エージェント定義は `src/lib/agents.ts`。
